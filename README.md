# Employee Promotion Prediction using Scikit-learn

This project predicts whether an employee may be promoted based on performance, training, education, experience, and previous promotion history.

## Run
1. Install dependencies:
   pip install -r requirements.txt
2. Train the model:
   python train_model.py
3. Make a sample prediction:
   python predict.py

The project includes a synthetic dataset in `data/employee_promotion.csv`.
