# Employee Promotion Prediction using Machine Learning

## Project Description

Employee Promotion Prediction is a Machine Learning project that predicts whether an employee is likely to be recommended for promotion based on different employee-related factors.

The project uses a **Random Forest Classifier** from Scikit-learn to analyze employee information such as performance, experience, training, education, previous promotions, and job satisfaction.

A **Streamlit web application** is included where users can enter employee details and receive a promotion prediction along with the probability of promotion.

## Features

* Predicts employee promotion eligibility using Machine Learning
* Uses Random Forest Classification
* Provides promotion probability
* Interactive Streamlit web interface
* Employee evaluation using multiple HR-related factors
* Pre-configured employee profiles for quick testing
* Feature importance visualization
* Displays the training dataset
* Saves the trained Machine Learning model using Joblib

## Machine Learning Features

The model uses the following features:

| Feature               | Description                                        |
| --------------------- | -------------------------------------------------- |
| Age                   | Age of the employee                                |
| Years at Company      | Total years the employee has worked in the company |
| Years in Current Role | Years spent in the current job role                |
| Performance Score     | Employee performance rating from 1 to 5            |
| Training Hours        | Total training hours completed                     |
| Education Level       | Education level of the employee                    |
| Previous Promotions   | Number of previous promotions                      |
| Job Satisfaction      | Job satisfaction rating from 1 to 5                |

### Target Variable

`promoted`

* `1` → Promoted
* `0` → Not Promoted

## How to Run the Project

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the Project Folder

```bash
cd Employee_Promotion_Prediction_Sklearn
```

### 3. Install Required Libraries

```bash
pip install -r requirements.txt
```

### 4. Train the Machine Learning Model

```bash
python train_model.py
```

This will:

* Load the employee dataset
* Split the data into training and testing sets
* Train the Random Forest model
* Evaluate the model
* Save the trained model
* Generate the feature importance chart

### 5. Run the Streamlit Application

```bash
streamlit run app.py
```

The application will open in your browser.

## Web Application

The Streamlit application contains three main sections:

### Employee Evaluation & Prediction

Users can enter employee information such as age, experience, performance, training, education, previous promotions, and job satisfaction.

The application then predicts whether the employee is recommended for promotion and displays the estimated promotion probability.

### Model Insights & Feature Importance

This section displays the feature importance generated by the Random Forest model.

It helps understand which employee-related factors contributed more to the model's predictions.

### HR Records Dataset

This section displays the employee dataset used for training and provides basic information such as:

* Total employee records
* Promotion rate
* Number of features
